# Gemma4Tunnel Open Tunnelling Corpus

This dataset is generated from a Zotero library by the Gemma4Tunnel cloud pipeline.

## Required files

- `train.jsonl`
- `validation.jsonl`
- `license_audit.csv`

## Licensing

Only sources classified as suitable for public training are included in the JSONL files. Review `license_audit.csv` before training or publishing a model.

## Intended use

Fine-tuning and evaluating TBM/tunnelling engineering language models.

## Limitations

This dataset is not legal advice and may contain extraction errors from PDFs.
